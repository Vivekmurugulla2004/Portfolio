# Portfolio Website

Personal portfolio for Vivek Murugulla — single-page site built with plain HTML, CSS, and JavaScript (no frameworks, no build step).

## Structure

- `index.html` — all page content
- `styles.css` — design system and layout
- `script.js` — accordion/tab interactions, scroll effects, resume preview modal
- `Vivek_Murugulla_Resume_MSBA.pdf` — resume, served directly by the site
- `robots.txt`, `sitemap.xml` — SEO

## Running locally

```
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
